# **SmartFlow AI: Edge Vision for Adaptive Traffic Management**

# 🌍 The Problem
Currently, over 80% of urban traffic signals operate on static, "dumb" fixed timers.
This outdated approach leads to:
**Massive Fuel Waste & Emissions:** Vehicles idle at red lights even when cross-traffic lanes are completely empty.
**Emergency Delays:** Ambulances and fire engines get trapped in artificial gridlock, losing the critical "Golden Hour. 
**"High Infrastructure Costs:** Traditional smart upgrades require digging up roads to install expensive inductive loops or LiDAR sensors.

# 💡 The ML Solution 
SmartFlow is a low-cost, hardware-agnostic retrofit. It transforms existing CCTV cameras into intelligent traffic sensors using Computer Vision (YOLOv8) and Edge AI.
By calculating real-time vehicle density ("Lane Pressure"), the system replaces static timers with a dynamic, heuristic state machine.

**🧠 Core AI & ML Concepts Applied:**
Object Detection: Utilizing the YOLOv8 Nano model for high-speed, lightweight vehicle detection on edge devices.
**Heuristic Optimization:** An algorithm that weighs queue lengths, waiting times, and emergency vehicle presence to determine optimal signal phases.
**Cyber-Physical Digital Twin:** A simulation bridging the gap between ML bounding boxes and physical traffic light actuation.

# 🚀 How to Run the Project
**Part 1:** The Edge ML Sensor (Python)This script acts as the software running on the pole-mounted camera (e.g., an NVIDIA Jetson Nano). It uses YOLOv8 to detect vehicles in a specific Region of Interest (ROI) and calculates Lane Pressure.
Prerequisites:
You will need Python installed on your system.
Open your terminal and navigate to the ML_Sensor folder.
Install the required AI libraries:pip install opencv-python ultralytics numpy
Run the detector:python vehicle_detector.py

**Note:** By default, the script is configured to use your laptop's webcam (video_source = 0) to demonstrate real-time live detection. Point it at yourself or traffic outside your window to see it count objects in the detection zone!

**Part 2:** The Digital Twin Simulation (Web)
Because we cannot hook the Python script up to a real city intersection, we built a Digital Twin to visualize how the "Lane Pressure" data generated by the ML sensor actuates the traffic lights and impacts the environment.
Navigate to the Digital_Twin folder.
Double-click index.html to open it in any modern web browser (Chrome, Edge, Safari). 
*No local server is required.*

Usage:Toggle between FIXED TIMER and AI ACTIVE modes to compare efficiency.
Click SPAWN AMBULANCE to test the AI's emergency preemptive override.
*Watch the Sustainability Metrics track fuel and CO2 savings in real-time.*

**🛠️ Key Features Highlight**
*🚑 Emergency Green Corridor: The AI assigns an absolute priority score to ambulances, safely clearing the intersection without causing accidents.
🌍 Carbon Footprint Tracker: Calculates idle-time reduction, estimating real-world drops in kg CO2 per hour.
🛡️ Fail-Safe Protocol: If camera visibility drops (simulated via weather conditions), the system automatically gracefully degrades to a standard fixed-timer pattern.*
